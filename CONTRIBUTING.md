# Mitarbeit

- Issues und Pull Requests sind willkommen. **Keine Kundendaten, Gerätenamen, Hostnamen oder Profildateien** in Issues, Logs oder Screenshots.
- Sicherheitslücken: siehe `SECURITY.md`.
- Sprache: UI-Texte, Doku und Logs Deutsch (mit Englisch über `Strings.cs`), Code-Bezeichner Englisch.
- Jeder sichtbare Text läuft über `Loc` (`Strings.cs`, DE und EN). Neue Hilfe-Anker in `de.html` und `en.html`.
- Vor dem Pull Request: `dotnet build VpnSwitch.slnx -c Release` und `dotnet run --project tests/VpnSwitch.Tests -c Release`.
- Firmenname immer **SPÄNI Elektro-Mechanik AG**.
